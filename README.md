## Наименование темы: 
### Цифровая модель оценки вероятности смешиваемости растворителей
В разработке средств защиты растений одна из востребованных препаративных форм является концентрат эмульсии. При разработке концентратов эмульсии большое количество экспериментов уходит на подбор растворителей, со-растворителей, ПАВ-ов и их соотношение в конечном продукте. Для уменьшения времени разработки  данной препаративной формы можно воспользоваться теорией растворимости Хансена, которая предсказывает будут ли смешиваться растворители или нет.

__В теории растворимости Хансена__ главенствует принцип -  подобное растворяется в подобном. Каждому веществу присваиваются 3 составляющих:
1. Дисперсионная - $\delta_{D}$;
2. Полярная - $\delta_{P}$;
3. Водородная - $\delta_{H}$;

Для оценки совместимости двух веществ вычисляют «расстояние» $R_{a}$ между их точками в пространстве Хансена:

$R_{a}^2 = 4(\delta_{D_2} - \delta_{D_1})^2 + (\delta_{P_2} - \delta_{P_1})^2 + (\delta_{H_2} - \delta_{H_1})^2$

Чем меньше значение $R_{a}$, тем "подобнее" являются соединения, а значит выше вероятность смешаться друг с другом.<br>

Основной проблемой использования теорией растворимости Хансена является отсутствие бесплатных баз данных, в которых находятся компоненты, входящие в уравнение для вычисление расстояния между точками в пространстве Хансена.

__Идея проекта:__<br>
Cоздать сервис, который по наименованию растворителей (SMILES, CAS) и их соотношению, будет предсказывать компоненты в уравнении Хансена (дисперсионную, полярную, водородную) и рассчитывать расстояние между точками в пространстве Хансена.

__Данный сервис позволит:__<br>
- позволит химикам-разработчикам из разных областей  ускорить процесс разработки;
- сэкономить огромное количество ресурсов компаниям, активно ведущие разработку;
- отличный тренажер для освоения принципа "подобное растворяется в подобном" для школьников и студентов;
